# Workspace theme

The CRM light and dark screenshots supplied on 25 November 2026 are the reference for shared application surfaces. Sampled light canvas #F8F9FB, table #FEFEFF, sidebar #FFFEFF, borders #DFE5EB; dark canvas #0A0D15, table #0F1219, sidebar #0F1119, borders #222730. The screenshot blue #3E83F6 is used for focus; filled primary buttons use #2563D9 for stronger contrast with white text. Single-level tables use neutral header colors #E7EAEF / #1B212B. Group header tokens preserve the reference's information, related, lead and admission tones for future grouped columns; they do not add grouped columns or CRM features. Purple is limited to the optional related group color and is not a global accent.

Shared theme tokens control dashboard, shell, mobile navigation, cards, dialogs, forms, inputs, tables, toolbars, status badges and pagination. Dedicated public-site and authentication illustration tokens remain intact. Legacy shell overrides are migrated to semantic tokens where present. No API or layout behavior is changed.
