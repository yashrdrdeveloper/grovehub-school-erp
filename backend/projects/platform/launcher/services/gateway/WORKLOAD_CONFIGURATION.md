# Platform workload configuration

Set PLATFORM_WORKLOAD_CONFIG to a JSON object with Keys and Routes. Each key has KeyID, PublicKey (unpadded base64url Ed25519), Issuer, Subject, Scopes and AllowDelegation. Routes maps exact method + registered restricted route to Scope and RequireActor. Audience is platform. Empty configuration denies new workload calls; Gmail webhook retains its existing dedicated verifier. Only login and forgot-password can be configured without a delegated actor at this stage. Delegated Identity and Audit calls require signed session ID, tenant and person GID; Platform reloads the active account/session and applies the existing protected-route RBAC policy. Foundation and Integration delegated policies and remaining authentication flows are not yet enabled. Keep private signing keys in consumers, never Platform. Do not deploy until tests and application wrappers are complete.
