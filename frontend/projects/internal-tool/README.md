# Internal Tool frontend

Independent React/Vite application at http://127.0.0.1:4174, proxying only /internal to the Internal Tool backend at 127.0.0.1:8082. Uses shared Base, Components and Styles with project-owned session, navigation and domains. No School imports or direct Platform requests. Install from repository root with pnpm install --frozen-lockfile; pnpm --filter @groovehub/internal-tool dev/build/test. Configure backend INTERNAL_TOOL_ALLOWED_ORIGIN=http://127.0.0.1:4174, run migrations and bootstrap an operator first. Production requires its own HTTPS origin and same-origin /internal ingress. Never rewrite Secure cookies to support plain HTTP; use browser-supported loopback or HTTPS.

Screens: login, requests, approval inbox/bulk approval, template registry, environments, operators, local workflow history. Supports request detail, approve/reject/cancel/execute and reconciliation. L2-only navigation and actions are presentation controls; backend authorization remains authoritative. New requests select from first 100 registry results; full registry pagination is available on registry pages. Template/input editing is JSON-based for the initial implementation. Registry, requests, approvals, operators and history use the shared universal Table with server pagination and stable column IDs; login has a shared form, responsive brand templates, dedicated hook, literal copy constants and a scoped CSS Module. Fully schema-driven controls, remaining page decomposition, full guideline verification and browser E2E are subsequent work. The root workspace/lockfile remains during package migration.
